# Collaborative sessions implementation

Approved integration: local authoritative MR Studio display; GitHub Pages phone client;
four shared editor slots plus spectators; existing desktop retained; per-layer Controls/Map;
Isovist, comfort routing, additive 2D CFD obstacles; author-owned Canvas;
local admin/presence/QR/logs; one start_services.sh; small commits.

Phases: (1) supervisor/local persistence (2) protocol and host adapters
(3) mobile drawer/dashboard (4) companion map (5) Canvas (6) admin/logs
(7) regression checks and Pages deployment.

The session directory retains the prototype's client.html, index.html, js and css
structure. Session logs and runtime configuration are never in the public client artifact.
